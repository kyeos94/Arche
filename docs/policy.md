# 가상 회사 정책서

가상의 대부업체 **예시대부(가상)** 한 곳의 정책입니다. 모든 숫자는 법정 상한 안에서 구현 편의를 위해 임의로 정한 값이며, 어떤 실제 회사의 기준도 아닙니다. 구현과 테스트는 이 탭을 유일한 기준으로 삼습니다.

## 1-1. 자유상환·매입채권 규칙

대부·NPL 업무에서는 회차별 원금 스케줄이 없는 자유상환 계약이 다수입니다. 이 경우 “회차 원금” 개념이 없으므로, 2장의 스케줄 규칙 대신 아래 규칙을 적용합니다. 없는 항목은 본문 규칙을 따릅니다.

### P5 자유상환 (신규 대출)

| 항목 | 정책 |
| --- | --- |
| 납부 의무 | 매월 약정일까지 그때까지 발생한 이자(최소 납부액)를 내야 함. 원금은 만기 전까지 언제든 일부 또는 전액 상환 |
| 스케줄 | 원금 스케줄 없음. 화면에는 “다음 약정일 최소 납부액(예상 이자)”과 “오늘 완제 금액”만 표시 |
| 이자 | 실제 잔액 × 연이율 × 일수 ÷ 365, 마지막 이자 정산일부터 입금일(기산일)까지. 원금을 일부 갚으면 입금일(기산일)부터 줄어든 잔액으로 계산 (한편넣기 \[from, to)). 휴일 유예 납부는 R13 |
| 충당 | 4장 순서와 같음. 비용·이자를 다 채운 나머지는 고객 요청이 없어도 자동으로 원금 상환 (가수금으로 보관하지 않음) |
| 연체 | 약정일(휴일이면 유예 영업일)까지 그때까지 발생한 이자를 다 내지 않으면 다음 날부터 연체. 미납 원금이 없으므로 상실 전에는 가산이자 없음 |
| 기한이익상실 | 이자 미납이 약정일부터 1개월 지속되면 통지 후 10영업일째 상실 (본문 3장 절차). 상실 후 전체 잔액 × 연체이율 |
| 만기 | 만기일에 잔액 전액 도래. 미상환 시 다음 날부터 전체 잔액 × 연체이율. 만기 연장은 재심사 후 최대 12개월씩 |
| 중도상환수수료 | 없음 |

### N1 매입채권 (NPL)

다른 금융회사에서 양수한 채권은 대부분 이미 기한이익상실 상태로, 납부 일정 없이 채무자가 갚는 만큼 충당하는 방식으로 관리합니다.

| 항목 | 정책 |
| --- | --- |
| 양수 등록 | 취득일, 취득가, 양도인, 원채권 계약일·약정이율·연체이율(R17), 양수 시점 잔액(원금, 미수이자, 비용을 구분), 원채권의 기한이익상실일·소멸시효 기산일·판결 여부 |
| 양수 후 이자 | 채권별 설정: “부과”(원금 잔액 × 적용이율, 적용이율 = min(원채권 연체이율, 20%)) 또는 “중단”(이자 없이 양수 잔액만 청구). 기본값은 부과 |
| 양수 전 미수이자 | 별도 잔액 항목으로 보관. 이 금액에는 이자를 붙이지 않음 |
| 충당 순서 | 비용 → 양수 후 발생 이자 → 양수 전 미수이자 → 원금 |
| 분할납부 약속 | 채무자와 “매월 n일에 m원” 약속을 등록. 스케줄을 재산출하지 않고, 약속별 이행 여부만 추적 (약속일 다음 날까지 약속액의 90% 이상 입금이면 이행) |
| 약속 불이행 | 1회 불이행은 담당자 알림, 3회 연속 불이행이면 약속 해제 후 법조치 검토 대상 |
| 약속 중 추심 | 약속 이행 중에는 자동 연체 문자 발송 안 함 (납부 안내만) |
| 관리 지표 | 연체일수 대신 “마지막 입금일로부터 경과일수”와 “취득가 대비 누적 회수율”을 표시 |
| 소멸시효 | 원채권의 기산일·중단 이력을 승계. 양수 시 이미 완성된 채권은 등록 시 경고하고 추심 연락 차단 |
| 완제 | 양수 잔액(원금 + 미수이자 + 비용)과 양수 후 이자를 모두 회수하면 완제. 채무조정으로 감면한 뒤 조정액을 다 내면 “조정 완제”로 구분 |

두 방식 모두 입금마다 잔액이 바뀌므로, 이자 계산은 본문의 구간 분할 방식(잔액 변경일을 경계로 구간을 나눔)을 그대로 씁니다. 소급 입금 재계산도 동일합니다.

## 2. 스케줄·이자 계산

| 항목 | 정책 |
| --- | --- |
| 연 일수 | 365일 고정 (윤년도 365) |
| 기간 계산 | 한편넣기: 시작일 포함, 종료일 제외 `[from, to)`. 단, 당일 실행·당일 상환은 1일분 이자 |
| 이자 방식 | 실제 잔액 기준 일할 계산: 잔액 × 연이율 × 일수 ÷ 365 |
| 단수 처리 | 잔액·금리가 일정한 구간마다 원 미만 절사 후 합산 |
| 약정일 | 고객이 5·10·15·20·25일 중 선택 |
| 첫 납입일 | 실행일의 다음 달 약정일. 실행일과의 간격이 15일 미만이면 그다음 달 |
| 원리금균등 납입액 | 월이율(연이율÷12) 공식으로 구해 원 미만 절사, 실행 시 고정 |
| 회차 원금 | 원리금균등: 납입액 − 그 회차 일할 이자 / 원금균등: 원금 ÷ 회차수(절사). 마지막 회차는 남은 잔액 전체 |
| 원금 스케줄 고정 | 회차별 원금은 실행 시 확정하고 재산출 사유(금리·약정일 변경, 일부 중도상환, 채무조정) 전까지 고정. 이자는 납부 시점까지 실제 발생액 |
| 휴일 | 약정일이 토·일·공휴일이면 다음 영업일까지 납부 시 연체 아님. 이때 이자는 약정일까지만 계산 |

## 3. 연체·기한이익상실

| 항목 | 정책 |
| --- | --- |
| 연체 시작 | 약정일(휴일이면 유예 영업일)까지 해당 회차 원금을 다 내지 않으면 다음 날부터 연체 |
| 연체일수 | 기준일 − 가장 오래된 미납 회차의 약정일 (유예를 넘기면 약정일부터 소급) |
| 연체이율 | min(약정이율 + 3.0%p, 20.0%) |
| 상실 전 연체이자 | 정상이자(전체 잔액 × 약정이율) + 가산이자(미납 원금 × (연체이율 − 약정이율)) |
| 상실 후 연체이자 | 전체 잔액 × 연체이율 (= 정상이자 + 전체 잔액 × 가산분) |
| 이자의 이자 | 부과하지 않음 (미납 이자에는 연체이자 없음) |
| 기한이익상실 사유 | 분할상환: 2회차 연속 연체 / 만기일시·자유상환: 이자 약정일부터 1개월 연체 / 매입채권: 해당 없음(양수 시 이미 상실) |
| 상실 절차 | 사유 발생일에 통지 발송 → 도달일(발송일 + 2영업일로 간주, 등기 배달 조회로 실제 도달일이 확인되면 그 날) 다음 영업일부터 세어 10번째 영업일에 상실 (그날부터 상실 후 이율). 그 전에 연체를 모두 해소하면 절차 취소 |
| 만기 미상환 | 만기일 다음 날부터 전체 잔액 × 연체이율 (별도 통지 불필요) |

## 4. 입금 충당·중도상환

| 항목 | 정책 |
| --- | --- |
| 충당 순서 | 비용 → 연체이자(가산분) → 정상이자 → 연체 원금(오래된 회차부터) → 납입일 도래 원금 → 중도상환 |
| 이자 정산 시점 | 연체 중 입금, 자유상환·매입채권 입금, 중도상환 요청 입금은 입금일(기산일)까지의 이자를 먼저 정산. 연체 없는 분할상환 계약의 약정일 전 입금은 다음 행 |
| 납입일 전 입금 | 가수금으로 보관했다가 약정일에 충당 (이자는 스케줄대로 약정일까지). 납입액을 넘는 금액도 가수금으로 두고, 고객이 중도상환을 요청할 때만 입금일 기준으로 원금 상환. 연체 중 입금이 연체금을 넘으면 남는 금액도 가수금 |
| 중도상환수수료 | 상환원금 × 수수료율 × 잔존일수 ÷ 기준일수 (원 미만 절사) |
| 기준일수 | min(대출기간 일수, 1,095일) |
| 잔존일수 | 기준일수 − 실행일부터 경과일수 (0 이하면 면제). 실행 후 3년이 지나면 항상 면제 |
| 일부 중도상환 | 남은 회차 수(만기)는 유지하고 납입액을 줄임. 계산식은 9장 R7 |
| 과입금 | 완제 후 남는 금액은 반환 대기 (7영업일 안에 반환) |

## 5. 채권 처분·소멸시효

| 항목 | 정책 |
| --- | --- |
| 채무조정 | 연체이자 전액 감면까지는 담당자, 정상이자 감면은 팀장, 원금 감면은 본부장 결재. 분할 최대 60회, 조정 후 3회차 연속 미납 시 감면액을 되살리고 기한이익상실 상태로 복귀(R9) |
| 상각 후보 | 기한이익상실 후 180일 경과 + 최근 90일 입금 없음 → 월말 배치가 후보 산출, 본부장 결재로 확정 |
| 매각 | 상각 채권 또는 기한이익상실 채권만 대상, 양도 통지 발송 이력 필수 |
| 환매 | 매각 후 6개월 안에 하자(서류 누락, 소멸시효 완성 등) 발견 시 매각가로 되사서 이전 상태로 복원 |
| 소멸시효 | 기산일: 기한이익상실일 또는 만기일. 기간 5년, 판결·지급명령 확정 후 10년. 입금(일부 변제)·압류·지급명령 신청 시 중단되고 그날부터 다시 기산 |
| 완성일 계산 | 기산일 다음 날부터 세어 N년이 되는 날의 끝 (초일불산입). 예: 2026-06-26 기산, 5년 → 2031-06-26 |
| 임박 알림 | 완성 180일·90일·30일 전 담당자 알림 |

| R22 | 중도상환 세부 | 원금균등 재산출은 새 잔액 ÷ m 절사, 마지막 회차에서 잔액 정산. 연체 중 요청은 연체금을 먼저 충당하고 남는 금액만 중도상환. 약정일 당일 요청은 그 회차 납입을 먼저 처리 |
| R23 | 채무조정 체결 조건 | 미감면 이자를 체결일에 납부해야 체결 완료. 미납이면 체결하지 않음 |

## 10. 입금 취소·정정

화면에는 “입금 삭제” 버튼을 두되, 내부적으로는 원장을 지우지 않고 취소 거래와 재계산으로 처리합니다. 입금 취소는 소급 입금(5.3)의 반대 방향입니다.

| # | 항목 | 확정 규칙 |
| --- | --- | --- |
| R26 | 취소의 의미 | 원 입금의 충당 거래마다 그것을 가리키는 REVERSAL 거래(reversalOfId)를 남긴 뒤(superseded는 저장 컬럼이 아니라 ‘REVERSAL이 가리키는 거래’라는 파생 상태), 원 입금의 기산일부터 그 입금이 없었던 것처럼 이후 거래를 다시 충당(재생). 어떤 원장 행도 UPDATE·DELETE 하지 않음. 취소된 돈은 사라지지 않고 미확인 입금(OPEN)으로 돌아감 (은행 측 입금 취소면 Payment.status = REVERSED). 단, 금액 오입력 정정(R30)에서 실제로 들어오지 않은 금액은 미확인 입금으로 남기지 않고 원 Payment를 CANCELLED로 닫음 |
| R27 | 당일 취소 (마감 전) | 처리한 본인 또는 채권팀장, 사유 입력 필수. 일보에는 취소된 입금이 나타나지 않음 |
| R28 | 마감 후 취소 | 시스템관리자 처리 + 채권팀장 승인, 사유 필수. 재계산은 R26과 같지만, 이미 마감된 날의 일보·대사 결과는 바꾸지 않고 차액을 취소 처리일 일보의 “정정” 항목으로 표시 |
| R29 | 재계산의 부수 효과 | 연체가 생기면 연체일수·가산이자는 원래 약정일부터. 기한이익상실 사유가 과거에 생겼어야 하는 경우에도 상실을 소급하지 않고, 취소 처리일을 사유 발생일로 보고 통지 절차(R15)를 새로 시작. 이미 발송한 문자·통지 이력은 그대로 둠. 취소된 입금은 소멸시효 중단(승인) 효력이 없으므로 완성 예정일 재계산. 신용정보 보고 정정은 범위 밖(대상만 기록) |
| R30 | 정정 | 잘못된 계약 충당 = A 계약 취소 + B 계약에 원 입금의 은행 거래일자로 소급 입금(기산일은 B 계약 기준으로 R13을 다시 적용. 예: G28). 금액 오입력 = 취소 + 올바른 금액으로 같은 기산일 재입력. 두 단계를 하나의 트랜잭션·하나의 정정번호(`PaymentCorrection`)로 묶음. 권한은 R27·R28과 같음 |
| R31 | 제한 | 완제·매각·상각 확정 후에는 그 이전 입금을 취소할 수 없음 (상태를 먼저 되돌리는 절차는 범위 밖). 취소도 계약 단위 락을 잡고 처리 |
